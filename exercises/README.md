# Exercises

- Demonstrate incorrect host timing of an async kernel, then fix it.
- Measure warm-up/cold-start effects.
- Sweep block size and correlate runtime with occupancy/register use.
- Estimate arithmetic intensity and place a workload qualitatively on a Roofline.
- Compare naive and tiled GEMM.
- Inspect PTX/SASS only after profiling identifies a reason to go lower.
